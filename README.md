# Calisthenics Trainer

A phone-first web app that builds a weekly calisthenics plan from a large
bodyweight catalog. Pick a difficulty, how many days you train, and the gear
you have. Each day hits a different muscle. Swap exercises, check off sets,
and keep the week in the browser.

## Tech stack

- React + Vite + TypeScript
- Tailwind CSS
- React Router
- Zustand + `localStorage` (no backend)

Hosted on GitHub Pages. A push or merge to `main` runs tests, builds, and
deploys.

## Getting started

```bash
npm install
npm run dev      # start the dev server
npm test         # unit tests
npm run build    # typecheck + production build
```
